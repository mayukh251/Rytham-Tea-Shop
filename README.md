# Rhythm Tea Co. — Royal Prebiotic Tea Brand Website

A premium, modern web application for **Rhythm Tea Co.**, a botanical wellness brand merging historic royal brewing traditions with contemporary gut microbiome and prebiotic testing.

Built using **React, TypeScript, Vite, and Tailwind CSS v4**.

---

## 🌟 Key Features

* **Rotating Announcement Banner**: Sleek promotional banner alerting users to prebiotic monographs and shipping benefits.
* **Navbar**: Sticky navigation featuring the brand logo **Rhythm** and links to the catalog.
* **Full-Bleed Pinned Scroll Animation (Hero)**: High-performance scroll sequence utilizing `canvas` drawing that maps the user's scroll track across 192 detailed sequence frames.
* **The Royal Collection**: Responsive 3-column catalog featuring six premium Indian teas:
  * *Darjeeling Tea (DJ-01®)* — Muscatel first flush notes.
  * *Assam Tea (AS-02™)* — Robust prebiotic black tea.
  * *Nilgiri Tea (NL-03™)* — High-altitude winter frost tea.
  * *Masala Tea Blend (MS-04®)* — Spiced cardamom, ginger, and black pepper.
  * *Kashmiri Kahwa (KW-05™)* — Saffron, almonds, and green tea.
  * *Kangra Tea (KN-06™)* — Rare high-altitude green tea.
* **Prebiotic Science Panel**: Modern layout with an auto-playing, looping video highlighting scientific gut-brain axis research.
* **Botanical Directory**: Clickable lab monographs listing third-party verified constituents (e.g. catechins, ORAC value, active terpenes) for each tea.
* **Ritual Quiz**: Interactive matching profiler aligning user goals and schedules to their ideal botanical match.
* **Cart Drawer**: Checkout system with one-time/subscription pricing (15% off) and promo code support (use code `BOTANICAL` for 10% off).

---

## 🎨 Design System Compliance

* **Flat Aesthetic**: 0 shadows or elevation drops.
* **Color Palette**: Restricted to Forest Depths (`#1c3a13`), Snow White (`#fcfcf7`), Lime Pulse (`#d3fa99`), Sage Moss (`#757c5d`), Olive Gold (`#9f995b`), Eucalyptus (`#698e79`), Warm Stone (`#eeeee9`), and Frosted Glass (`#c4c7c4`).
* **Interactive Elements**: Fully rounded (1000px radius) pills and buttons.
* **Typography**: Clean headings (Inter, light weights) paired with monospaced data tags (JetBrains Mono).

## 🚀 How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/mayukh251/Rytham-Tea-Shop.git
   cd Rytham-Tea-Shop
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Start Development Server**:
   ```bash
   npm run dev
   ```
4. **Compile Production Build**:
   ```bash
   npm run build
   ```
